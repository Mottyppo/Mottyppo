## Hi, I’m Matteo 👋

I’m a Computer Engineering Master’s student at the University of Brescia with a passion for software development in all its forms — although the gym is a close competitor.

My main interest is back-end development, particularly with Java / Spring Boot and Python / FastAPI, but I enjoy working across the entire software stack and exploring different fields of computer science.

Over the years, I’ve worked as a freelance developer on small management systems and interactive applications, including games and experiences for themed events, using technologies such as Flutter and React.

I’ve also worked with Laravel for full-stack web development and Python for computer vision, data analysis and automation.

## 🤖 My take on AI

I see AI in software engineering much like the relationship between an architect and the people who build what they design.

The engineer should understand the problem, design the architecture, make the important technical decisions and evaluate the trade-offs. AI can then take care of much of the implementation’s heavy lifting.

**AI can write the code. The engineer should know what to build, how to design it, and why.**
